## 1. 研究課題

低価格ロボットアーム（SO-ARM101、Feetech STS3215）によるラボサンプル移送タスクにおいて、
**センサー構成とデモンストレーション収録方法が、模倣学習方策のエンドツーエンド成功率にどう影響するか**を定量化する。
併せて、同一タスクにおける**非学習ベースライン（waypoint再生）との費用対効果**を比較する。

### 背景（先行する予備実験の知見）
リモコン把持タスク（60デモ、ACT/SmolVLA）の技術監査により、失敗が2段階に分解されることを確認済み：
①閉じ行動のロールアウト発火信頼性（アーキテクチャ依存: ACT 2/5、SmolVLA 0/6。offline予測は両者完璧）
②発火位置の空間精度（phantom grasp）。
本実験のC1（手首カメラ）は②、C2（corrective demo）は①への対策仮説である。詳細: `../audit_report.md`

## 2. 仮説（反証可能）

- **H1**: 手首カメラの追加（C0→C1）は把持成功率を15ポイント以上改善する
- **H2**: corrective demo 20本の追加（C1→C2）はエンドツーエンド成功率を15ポイント以上改善する
- **H3**: 固定位置条件では、waypointベースラインが学習方策のC0を成功率で上回る
- H1/H2が棄却された場合、その要因分析（failure taxonomyの変化）を報告する。「改善しなかった」も結果として報告する

## 3. タスク定義

**「ラックAの赤キャップチューブを取り、ラックBの指定スロットへ挿す」**

- 対象: 空のスクリュー管または遠沈管（15ml、キャップに赤シール）。実液体・危険物は使用しない
- 配置: ラックA（開始、6スロットの決まった1つ＋位置変動条件では±2スロット）、ラックB（目標スロット固定）
- 開始状態: アームはhome_pose（全関節中央）から。毎試行前に自動ホーミング
- 成功定義: チューブがラックBの指定スロットに直立で挿入され、アームが離した状態で試行時間内に静止
- 試行時間: 40秒

## 4. 実験条件（2段階・順次）

| 条件 | 入力・データ | 検証対象 |
|---|---|---|
| **B0** | waypoint再生（AIなし・固定位置） | 非学習ベースライン |
| **C0** | 固定カメラのみ / 60デモ / ACT | 基準 |
| **C1** | 固定+手首カメラ / 同一収録の60デモ / ACT | 視点追加の効果（H1） |
| **C2** | C1 + corrective demo 20本 / ACT | 修正データの効果（H2） |
| **C3** | C2 + CV成功確認 + 1回retry | closed-loop recovery |

- デモはC0/C1で共用するため**最初から2カメラ同時収録**する（C0学習時に手首視点を除外）
- モデルはACTに固定（監査でロールアウト発火実績、学習3.5h/100k、推論60Hz）。SmolVLAは最良条件確定後に同条件で1回だけ比較
- 学習ハイパーパラメータは全条件共通（100kステップ、image_transforms有効、既定値）

## 5. データ収集規程

- 60デモ = 開始位置6パターン × 10本（均等化）
- 各デモ: 掴む→持ち上げ→搬送→挿入→**離して1秒静止**まで収録（監査知見: 終端状態の収録漏れ防止）
- グリッパー閉鎖は各デモで1秒以上保持
- corrective demo（C2用）: C1評価の失敗3態様（把持ミス・搬送落下・位置ズレ）それぞれの状態から人間が復帰する様子のみを20本
- 照明・カメラ位置は全収録・全評価で固定。カメラ位置は基準画像との比較で毎セッション検証

## 6. 評価規程

- 各条件 **30試行**、毎試行前に自動ホーミング（`harness/run_trials.ps1`）
- 段階別採点（`harness/score_trials.py`、関節ログから自動 + 最終フレーム画像の目視確認）:
  対象到達 / 下降 / 安定把持(0.5秒以上) / 搬送 / 解放 / **正置（目視）** / エンドツーエンド
- failure taxonomy: no_attempt / grasp_fail / drop_in_transit(no_transfer) / no_release / misplace
- 付帯記録: 平均サイクル時間、人間介入回数、接続リトライ回数、モーター温度
- **判断基準はlossではなく独立試行の成功率のみ**

## 7. 中止条件（レジャー化防止）

- C2まで実施しても全工程成功率70%未満 → 完全自律を断念し、テレオペ支援/CV検査のみ/半自動へ方針転換
- 毎回異なる原因で失敗し再現性がない → ハード見直しへ
- 2週間を超えて成果物（動画+報告書）が出ない → 終了
- 追加ハード購入は本プロトコル記載分（手首カメラ1台）のみ

## 8. 成果物

- 条件別成功率の比較表 + failure taxonomy + 90秒デモ動画
- 技術報告書5-8ページ（和文、note/ワークショップ投稿可能な形）+ データセットカード
- 再現手順（本プロトコル + harness一式）

| 品目 | 仕様 | 用途 |

| 結束バンド・両面テープ | 手首カメラ固定用 | — |

## 10. 役割分担

- 人間: デモ収録（60+20本、計90分）、試行間の対象リセット、正置の目視判定、プロトコル逸脱の監視
- 自動（構築済み）: ホーミング、試行実行、リトライ、温度管理、段階別採点、CSV出力、夜間学習
